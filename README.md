# 概要
VRChatでの使用を想定した版ズレ風のテクスチャになるシェーダーです。
テクスチャ上の黒と白などコントラストが高い境界でよく働きます。

Thanks to:
* OpenLit : https://github.com/lilxyzw/OpenLit
